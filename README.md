# Hostel Booking App

A Python desktop frontend for browsing hostels and exploring the booking process.

## Technologies
- Python
- Tkinter / CustomTkinter
- tkcalendar

## Features
- Hostel listings
- Hostel details
- Booking interface
- Date selection
- Booking confirmation

## How to Run
Install the required Python packages, then run the main application file.

Example:
python3 maain.py

Replace maain.py with the correct entry-point filename if needed.
